## ADDED Requirements

### Requirement: Planning Agent handles multi-step reasoning tasks
The Planning Agent SHALL decompose complex, multi-step requests into sub-steps using chain-of-thought reasoning. It SHALL be able to invoke tools from both the Action Agent and Query Agent.

#### Scenario: Semester planning task
- **WHEN** a user asks "Plan my next semester avoiding Friday classes"
- **THEN** the Planning Agent decomposes the task into sub-steps (query available courses, filter by schedule, check prerequisites, propose a plan) and executes them

#### Scenario: Prerequisite analysis
- **WHEN** a user asks "What prerequisites am I missing for the ML track?"
- **THEN** the Planning Agent queries the user's completed courses, retrieves ML track requirements, and computes the gap

### Requirement: Planning Agent sub-steps are individually safety-checked
Each sub-step generated by the Planning Agent that involves a write operation SHALL be individually evaluated by the safety system.

#### Scenario: Multi-step plan with a write operation
- **WHEN** the Planning Agent decomposes a task that includes enrolling in a course
- **THEN** the enrollment sub-step is individually routed through the safety layer before execution

### Requirement: Planning Agent uses chain-of-thought system prompt
The Planning Agent SHALL use a system prompt designed for chain-of-thought task decomposition, including few-shot examples demonstrating multi-step reasoning.

#### Scenario: Planning Agent produces structured reasoning
- **WHEN** the Planning Agent processes a complex request
- **THEN** it produces a structured decomposition with numbered sub-steps before executing them
